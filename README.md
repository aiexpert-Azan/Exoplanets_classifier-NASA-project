**🪐Exoplanet Classifier — NASA Project**
**Overview**

This project is an AI/ML-powered Exoplanet Classification System built using NASA’s exoplanet catalogs such as KOI, TOI, and K2 datasets.
It predicts whether a candidate planet is a:

Confirmed Exoplanet

False Positive

Candidate

The model is trained using machine learning pipelines and can classify new exoplanet candidates based on physical and observational features.

**Features**

Streamlit-based interactive web interface

Upload your own NASA catalog .csv file

Automatic feature engineering

Instant prediction of planetary disposition

Downloadable prediction results

Fully modular and clean Python code structure

**Tech Stack**

Python 3.10+

Streamlit – for interactive web UI

Scikit-learn – for model training & prediction

Joblib – for saving/loading the trained model

Pandas & NumPy – for data processing and feature creation
